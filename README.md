# 电子信息研究生基础能力培养（持续更新）

本仓库用于智能感知与光电信息处理Lab研究生的系统性基础培养，统一管理培养要求、方向方案和项目验收标准。培养目标是使学生能够独立搭建环境、阅读技术资料、实现和调试系统、记录实验并逐步进入科研课题。

培养采用 **共同工程与科研规范 + 主方向专业训练 + 综合项目验收** 的组织方式。统一的是培养过程与能力标准，专业内容按嵌入式 STM32、FPGA 和计算机视觉分别设置。主方向由导师结合课题需求与学生基础确定，进度按能力模块记录，不以统一周数代替掌握程度。

## 从这里开始

1. 学生与导师确定主方向，阅读本页共同要求和对应方向方案。
2. 科研培养方向负责人确定当前模块、实践任务、验收方式与预期交付。
3. 学生完成环境配置、基础实验和模块练习，提交代码及实验记录。
4. 阶段验收通过后进入综合项目；完成方向结业要求后衔接科研课题。

## 编程基础

1.Python 作为当下主流科研编程语言，掌握其基础并具备一定的编程实践能力，是顺利开展研究的重要前提。如果你已有C/C++的学习基础，Python的入门会非常顺畅。目前网络上优质的Python学习资源极为丰富，相信以各位同学的学习能力，完全可以通过自学快速上手。
2.Pytorch 是当前深度学习领域的主流框架，实验室的科研项目大多基于此平台构建。建议先通过 PyTorch 官网的 Tutorials 学习 Learn the Basics 部分打好根基，随后在具体研究项目中针对所用网络模型深入实践，逐步提升。
3.Vibe Coding 是当前极具效率的编程范式，但其最佳实践高度依赖项目经验与使用技巧。由于相关工具和方法迭代较快，建议多与有实际使用经验的师兄师姐交流，了解如何高效利用以及需要规避的常见问题。

## 三个方向的培养方案

| 方向 | 培养主线 | 核心实践 | 进入方案 |
| --- | --- | --- | --- |
| 嵌入式 STM32 | PCB、嵌入式 C、MCU、外设、DMA、FreeRTOS、可靠性 | 自研 STM32F407 四层板；多源采集、存储与多总线通信终端 | [STM32 培养方案](plans/stm32.md) |
| FPGA | 数字逻辑、RTL、自动验证、时序、CDC、片上资源、软硬件协同 | PL 端可配置多通道信号采集与实时处理系统 | [FPGA 培养方案](plans/fpga.md) |
| 计算机视觉 | Python、图像处理、数学与相机几何、PyTorch、视觉任务、论文复现 | 标定与测量、深度估计、检测分割或相关基线复现 | [计算机视觉培养方案](plans/computer-vision.md) |

三个方向可在综合项目中协作，例如嵌入式端负责采集与设备控制，FPGA 端负责实时处理，视觉端负责算法和评测。每名学生仍需证明主方向的独立能力。

## 共同基础要求

| 能力 | 训练要求 | 验收证据 |
| --- | --- | --- |
| Linux 与环境配置 | 掌握基本操作，能独立搭建本方向环境 | 依赖、版本与运行说明 |
| Git 与工程组织 | 代码纳入版本管理，目录和接口清晰 | 可追溯提交与完整项目 README |
| 实验记录与复现 | 保留配置、数据版本、结果、问题与排查过程 | 他人可重复主要实验 |
| 技术资料阅读 | 优先阅读官方手册、数据手册、框架文档和原始论文 | 阅读笔记及实际问题的解决依据 |
| 技术写作 | 说明需求、设计、实现、测试、问题和改进 | 技术报告及可核查测试结果 |
| 组会汇报 | 汇报已解决问题、未解决问题、证据与下一步 | 实验图表、问题记录与行动安排 |

## 培养过程与考核

以能力模块为单位管理进度。负责人可根据学生基础调整任务数量和难度，应保留核心内容和验收标准。每完成一个阶段，学生提交代码或工程文件、实验结果、问题记录和简要总结，并通过现场演示或汇报解释设计思路。

| 层级 | 考核重点 | 判断方式 |
| --- | --- | --- |
| 基础能力 | 本方向语言、工具和基本模块 | 按要求完成程序、模块或实验，解释主要参数 |
| 独立能力 | 缺少完整教程时完成任务 | 仅依据技术手册、论文或接口要求独立设计、实现和调试 |
| 科研能力 | 处理没有标准答案的问题 | 提出假设、设计实验、收集证据、分析失败并形成可复查结论 |

### 方向结业要求

- **STM32**：从采集或控制需求出发，完成硬件接口、驱动、实时任务、通信、上位机和可靠性测试；按本仓库首版任务书完成开发板与综合项目验收。
- **FPGA**：从功能规格出发，完成 RTL、测试平台、约束、实现、时序分析和板级验证；达到第一阶段综合项目规定的量化指标。
- **计算机视觉**：从研究问题出发，完成数据处理、基线复现、训练、评价、消融和误差分析；形成可重复运行的实验工程。

达到要求后转入具体科研课题，围绕课题补足平台、理论、数据集和论文写作能力。

## 提交与维护方式

本仓库管理培养方案。学生实验代码、硬件工程和大型数据建议在各自项目仓库中管理，在阶段记录中引用对应提交或版本。

每次阶段提交建议包含：任务与完成情况、代码版本、环境和运行方法、测试配置与结果、问题及排查过程、结论和下一步。长期课题保留稳定基线，改动使用独立分支或配置，保证结果可追溯。

培养方案修改通过提交或 Pull Request 记录；说明修改原因、影响方向以及验收标准变化。量化指标调整应由导师或方向负责人确认后更新，并保留历史版本。
