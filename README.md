# 电子信息研究生基础能力培养（持续更新）

## 一、培养目标

本仓库用于智能感知与光电信息处理Lab研究生的系统性基础培养，培养学生独立学习、工程开发、实验验证和科研创新的能力。采用**共同基础训练 → 主方向分阶段培养 → 综合项目验收 → 科研课题研究**的培养方式；按能力与项目成果考核

## 编程基础

1. Python 作为当下主流科研编程语言，掌握其基础并具备一定的编程实践能力，是顺利开展研究的重要前提。如果你已有C/C++的学习基础，Python的入门会非常顺畅。目前网络上优质的Python学习资源极为丰富，相信以各位同学的学习能力，完全可以通过自学快速上手。

2. Pytorch 是当前深度学习领域的主流框架，实验室的科研项目大多基于此平台构建。建议先通过 PyTorch 官网的 Tutorials 学习 Learn the Basics 部分打好根基，随后在具体研究项目中针对所用网络模型深入实践，逐步提升。

3. Vibe Coding 是当前极具效率的编程范式，但其最佳实践高度依赖项目经验与使用技巧。由于相关工具和方法迭代较快，建议多与有实际使用经验的师兄师姐交流，了解如何高效利用以及需要规避的常见问题。

## 二、培养流程

| 阶段 | 主要任务 | 阶段成果 |
| --- | --- | --- |
| 共同基础 | 掌握编程、开发环境、版本管理和实验规范 | 可运行的基础程序、环境与实验记录 |
| 主方向训练 | 完成对应方向的分阶段学习和项目 | 各阶段工程、结果演示及测试报告 |
| 综合项目 | 独立完成完整系统，开展性能测试与优化 | 可运行系统、源代码、指标与技术文档 |
| 科研课题 | 阅读论文、复现基线、提出改进并验证 | 可复现实验、阶段研究成果及学位论文工作 |

## 三、共同基础要求

| 模块 | 学习与实践要求 |
| --- | --- |
| 编程与工具 | 掌握Python基础；根据方向学习C/C++、PyTorch及相关开发工具 |
| 工程环境 | 熟悉Linux、开发环境配置、Git和模块化项目管理 |
| 技术资料 | 阅读官方手册、数据手册、框架文档和原始论文，解决实际问题 |
| 实验规范 | 保存代码、配置、数据版本、日志和结果，保证关键实验可复现 |
| 智能编程工具 | 可使用AI辅助编程，但须理解、检查并独立验证生成的代码 |
| 技术表达 | 能用图表、演示和简要报告说明方法、结果、问题及改进方向 |

## 四、三个方向的培养方案

| 方向 | 培养主线 | 综合项目 | 详细方案 |
| --- | --- | --- | --- |
| 嵌入式STM32 | PCB设计、嵌入式C、外设与DMA、通信、FreeRTOS、可靠性 | 自研STM32F407开发板与多源数据采集、存储及通信终端 | [STM32培养方案](plans/stm32.md) |
| FPGA | 数字逻辑、Verilog、图像处理、并行计算、软硬件协同与架构优化 | 实时图像处理与硬件加速系统 | [FPGA培养方案](plans/fpga.md) |
| 计算机视觉 | Python、图像处理、相机几何、PyTorch、视觉任务、论文复现 | 视觉测量、检测分割或三维视觉综合项目 | [计算机视觉培养方案](plans/computer-vision.md) |

各方向可在综合项目中协作，但每名学生须独立完成本方向的核心任务与验收。
## 五、培养过程与考核

以阶段项目为考核单元。每阶段提交**可运行代码或工程、可视化结果、关键指标、问题记录和简要总结**，通过演示与答辩后进入下一阶段。

| 考核层级 | 考核重点 | 验收方式 |
| --- | --- | --- |
| 基础能力 | 掌握本方向工具、原理和基本模块 | 独立完成基础实验并解释关键参数 |
| 工程能力 | 完成模块设计、调试和系统集成 | 展示运行效果，提交工程和测试数据 |
| 科研能力 | 发现问题、提出方法、开展对比与分析 | 提交基线、对比/消融结果及可复查结论 |

### 组会汇报要求

每次组会围绕**上次组会至本次组会的实际进展**汇报，重点说明：

| 汇报内容 | 具体要求 |
| --- | --- |
| 学习收获 | 学习了哪些知识、技术或论文 |
| 项目进展 | 独立完成了哪些模块、实验或阶段任务；提供代码或演示 |
| 可视化效果 | 展示实物运行、界面、图像、波形、曲线或其他结果 |
| 对比与指标 | 与什么基线或既有方案对比；报告精度、速度、资源、误差等相关指标及测试条件 |
| 新想法与认识 | 说明新的发现、原因分析、改进设想及下一步验证计划 |

**汇报原则：** 以实际结果和证据为主，不只罗列学习过程；未完成的任务需说明问题、已尝试的方法与下一步安排。

## 六、方向结业与科研衔接

| 方向 | 结业要求 |
| --- | --- |
| STM32 | 完成开发板、驱动、实时任务、通信和可靠性测试，通过综合项目验收 |
| FPGA | 完成核心计算模块、仿真、时序分析和板级验证，通过综合系统性能验收 |
| 计算机视觉 | 完成数据处理、基线复现、模型训练与评价、对比及误差分析，提交可复现实验工程 |

通过方向结业后进入具体科研课题，围绕明确的研究问题开展方法设计、实验验证与论文工作。
