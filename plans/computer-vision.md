# 计算机视觉方向培养方案

[返回总导航](../README.md)

本方向从 Python 科研编程、数字图像处理和相机几何出发，逐步进入 PyTorch、现代视觉任务与论文复现。实验应同时提供可复现工程、定量评价和误差分析。

## 培养目标

计算机视觉方向面向图像处理、视觉测量与深度学习研究。学生应掌握Python科研编程、经典图像处理、相机几何和PyTorch训练流程，能够完成论文复现、对比实验和误差分析，并进入实验室的具体视觉课题。

## 学习路线

Python与科学计算  →  数字图像处理与OpenCV  →  数学与相机几何  
PyTorch与深度学习  →  现代视觉任务  →  论文复现与方法改进

## 数字图像处理

数字图像处理是进入计算机视觉的基础，应理解图像表示并掌握以下主要算法。

| 学习模块 | 主要内容 |
| --- | --- |
| 图像表示 | 采样、量化、分辨率、通道、数据类型；RGB、灰度、HSV及颜色空间转换 |
| 灰度与直方图 | 灰度变换、直方图统计、直方图均衡化、对比度增强 |
| 空间滤波 | 均值滤波、高斯滤波、中值滤波、双边滤波 |
| 锐化与边缘 | Sobel、Scharr、Laplacian、Canny、非锐化掩蔽 |
| 阈值与分割 | 全局阈值、自适应阈值、Otsu、区域生长、分水岭 |
| 形态学与区域 | 腐蚀、膨胀、开闭运算、连通域、轮廓提取 |
| 几何变换 | 插值、缩放、旋转、仿射变换、透视变换和图像配准 |
| 频域处理 | 傅里叶变换、频谱分析、低通与高通滤波 |
| 形状与检测 | Hough直线与圆检测、模板匹配 |

## 数学基础

重点学习线性代数、概率统计、微积分与数值优化，包括矩阵运算、特征值、SVD、最小二乘、概率分布、导数、梯度及常用优化方法。三维视觉还需掌握齐次坐标、旋转矩阵、四元数、坐标变换和刚体运动。

## 经典视觉与相机几何

| 学习模块 | 主要内容 |
| --- | --- |
| 相机模型 | 针孔模型、内参、外参、镜头畸变、坐标系与相机标定 |
| 局部特征 | Harris、SIFT、ORB、特征描述、特征匹配和匹配筛选 |
| 鲁棒估计 | RANSAC、单应矩阵、基础矩阵和本质矩阵 |

## PyTorch与深度学习

掌握Tensor、自动求导、Dataset、DataLoader、模型定义、损失函数、优化器、GPU训练及模型保存，能够独立编写训练、验证和测试程序。

学习卷积、池化、感受野、激活函数、归一化、残差连接、正则化和数据增强，并通过LeNet、AlexNet、VGG和ResNet理解卷积网络结构。

## 论文阅读与科研实验

- 围绕研究问题、方法假设、网络结构、数据集、损失函数、评价指标和主要结论整理文献。

- 复现前固定软件环境、数据版本和随机种子，先验证基线结果，再进行方法改动。

- 方法改进应包含基线、对比实验、消融实验、定量结果、定性结果、计算成本和失败案例。

- 实验记录应保存配置、日志、模型权重、可视化结果和结论，确保结果可以重复。

## 实践项目

项目可选择相机标定与视觉测量、双目深度、目标检测、语义分割、单目深度与法向估计、点云重建相关论文复现。选题应与学生后续课题相连，并形成数据检查、算法实现、训练评测和结果分析的完整流程。

## 完成标准

- 能够独立配置Python与GPU环境，整理数据集并完成可重复运行的训练和测试工程。

- 能够正确说明相机模型、坐标系、数据范围和评价指标，定位常见的数据与几何错误。

- 能够复现一项基线方法，完成合理的对比、消融和误差分析。

- 能够将实验结果整理为图表、技术报告和组会汇报，并说明结论的适用范围。

## 科研衔接 三维视觉和偏振成像

三维视觉部分包括单目和双目深度估计、表面法向、点云表示、三维重建、位姿与坐标变换。学生应熟悉深度图、法向图和点图之间的关系，掌握相机内参在反投影中的作用，并能使用Open3D或同类工具完成点云读取、变换、可视化和误差计算。

结合实验室研究方向，应进一步学习偏振图像形成、Stokes参数、偏振度、偏振角、漫反射和镜面反射模型、法向歧义以及偏振与RGB、深度或多视图信息的融合。相关研究可继续延伸到Shape from Polarization、单目深度与法向联合估计、NeRF、3D Gaussian Splatting以及物理模型与深度网络结合。

这一部分不能停留在调用已有模型。学生需要检查数据标定、坐标约定、单位、掩膜、评价区域和可视化方法，明确性能提升来自网络结构、损失设计、数据处理还是物理先验。
