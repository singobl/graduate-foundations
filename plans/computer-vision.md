# 计算机视觉方向培养方案

[返回总导航](../README.md)

## 一、培养目标

面向计算机视觉与视觉测量研究，培养研究生的**科研编程、图像处理、相机几何、深度学习、实验分析和独立科研能力**。通过阶段项目逐步完成从算法实现到系统集成的训练，最终形成可复现的视觉系统及与硕士课题相关的研究成果。

**培养路线：** Python与图像处理 → 数学与相机几何 → PyTorch与模型训练 → 现代视觉任务 → 论文复现与方法改进 → 综合系统与学位研究。

## 二、分阶段培养内容

### 第一阶段：Python科研编程与数字图像处理

**培养目标：** 能独立搭建开发环境，编写图像处理程序，并解释图像数据与算法输出。

| 学习模块 | 主要内容 |
| --- | --- |
| 科研编程 | Python、Linux、Git、Conda/venv、Jupyter；代码组织与环境复现 |
| 科学计算 | NumPy、SciPy、Pandas、Matplotlib；矩阵运算、数据统计与可视化 |
| 图像处理 | OpenCV、scikit-image；图像格式、颜色空间、灰度变换和直方图 |
| 经典算法 | 滤波、边缘检测、阈值分割、形态学、几何变换与特征提取 |

**阶段项目：多功能图像处理与分析工具**

1. 实现图像读写、颜色空间转换、增强、滤波、边缘检测和分割。
2. 支持算法与参数切换，展示处理前后的图像及统计结果。
3. 对不同算法进行效果与运行时间比较，并分析典型失败情况。

**阶段成果：** 可运行的图像处理工程、测试图像、结果对比和简明技术报告。

### 第二阶段：数学基础、相机几何与三维视觉

**培养目标：** 掌握相机成像与多视几何，能够完成相机标定、图像匹配和基础三维计算。

| 学习模块 | 主要内容 |
| --- | --- |
| 数学基础 | 线性代数、概率统计、微积分、最小二乘与数值优化 |
| 几何表示 | 齐次坐标、旋转矩阵、四元数及坐标变换 |
| 相机模型 | 针孔模型、内外参、畸变、相机标定及重投影误差 |
| 经典视觉 | Harris/SIFT/ORB、特征匹配、RANSAC、PnP与位姿估计 |
| 多视几何 | 极线约束、双目校正、视差、三角化和深度恢复 |

**阶段项目：双目相机标定与三维测量**

1. 完成双目相机标定、畸变校正及图像校正。
2. 实现特征匹配或基础视差计算，依据相机参数恢复深度或三维点。
3. 对已知尺寸目标进行三维测量，分析重投影误差及测量误差。

**阶段成果：** 标定参数、双目几何处理程序、深度/点云结果和误差分析报告。

### 第三阶段：PyTorch与深度学习基础

**培养目标：** 能独立完成数据准备、网络构建、训练、验证、测试及模型结果分析。

| 学习模块 | 主要内容 |
| --- | --- |
| 深度学习基础 | Tensor、自动求导、卷积、归一化、残差连接与优化方法 |
| PyTorch开发 | Dataset、DataLoader、模型定义、损失函数、优化器和GPU训练 |
| 典型网络 | LeNet、AlexNet、VGG、ResNet及迁移学习 |
| 训练与评价 | 数据划分与增强、学习率、过拟合、Accuracy/F1、实验日志与权重保存 |

**阶段项目：基于PyTorch的图像分类系统**

1. 整理公开数据集，完成训练集、验证集和测试集划分。
2. 实现并训练基础分类网络，复现一个经典网络或使用预训练模型微调。
3. 对比不同模型或训练策略，分析准确率、推理时间和错误样本。

**阶段成果：** 可复现的训练/测试代码、模型权重、训练记录与评价报告。

### 第四阶段：现代视觉任务与模型应用

**培养目标：** 理解典型视觉网络及评价方法，能够独立训练和部署一个检测或分割模型。

| 学习模块 | 主要内容 |
| --- | --- |
| 目标检测 | YOLO、Faster R-CNN；特征提取、检测头、IoU和NMS |
| 图像分割 | FCN、U-Net、DeepLab；编码器、解码器与边界质量 |
| Vision Transformer | Attention、QKV、token、位置编码及ViT基础 |
| 预训练与评测 | 数据增强、迁移学习、Precision/Recall、F1、IoU、计算量与推理速度 |

**阶段项目：目标检测与分割应用系统**

1. 选择与后续课题相关的数据集，训练一个目标检测或语义分割模型。
2. 实现图像/视频推理、结果可视化和模型评测。
3. 分析精度、推理速度、复杂场景表现及失败案例。

**阶段成果：** 可运行的视觉任务工程、训练权重、评价结果及可视化演示。

### 第五阶段：论文复现、方法改进与科研训练

**培养目标：** 能围绕明确的研究问题建立基线、提出改进假设并完成规范的实验验证。

| 学习模块 | 主要内容 |
| --- | --- |
| 文献阅读 | 研究问题、方法假设、网络结构、数据集与评价指标 |
| 复现实验 | 固定环境、数据版本和随机种子；基线复现与偏差分析 |
| 方法研究 | 针对精度、鲁棒性、效率或几何一致性提出可检验的改进方案 |
| 实验分析 | 对比实验、消融实验、定量与定性评价、计算成本及失败案例 |
| 科研表达 | 实验记录、结果图表、技术报告、组会汇报与论文写作 |

**阶段项目：与学位课题相关的视觉方法复现及改进**

1. 选择一项相关论文方法，明确数据集、实现条件与评价指标。
2. 复现基线并记录与原论文结果的差异。
3. 围绕一个具体问题提出改进方法，完成对比、消融和误差分析。
4. 整理可重复运行的工程、实验数据和论文初稿或研究报告。

**阶段成果：** 稳定基线、经过验证的研究方案及学位论文核心实验材料。
