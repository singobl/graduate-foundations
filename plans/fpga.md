# FPGA 方向培养方案

[返回总导航](../README.md)
## 一、培养目标
面向电子信息类专业研究生，以FPGA硬件设计、并行计算和软硬件协同开发为基础，以**图像处理、计算加速和嵌入式系统设计**为主要应用方向，培养学生独立开展FPGA系统开发、硬件架构优化及科研工作的能力。

通过分阶段学习和项目实践，使学生逐步掌握从基础硬件设计到复杂系统开发的完整技术流程，最终独立完成具有实际应用价值的FPGA综合项目。

**总体培养路线：**

数字逻辑与Verilog基础 → FPGA图像处理 → FPGA系统设计 → 软硬件协同与算法加速 → 并行计算架构优化 → 综合系统开发与科研创新

---

## 二、分阶段培养内容

### 第一阶段：数字逻辑与FPGA基础

**培养目标：** 掌握数字电路基本原理和Verilog/VHDL硬件描述语言，具备独立完成简单FPGA系统设计、仿真及硬件调试的能力。

#### 1. 学习内容

| 培养模块 | 具体学习内容 |
|---|---|
| 数字逻辑基础 | 组合逻辑、时序逻辑、寄存器、计数器、有限状态机 |
| Verilog/VHDL语言 | 基本语法、模块化设计、组合逻辑与时序逻辑描述 |
| FPGA基础 | FPGA内部结构、LUT、BRAM、DSP及基本开发流程 |
| 开发工具 | Vivado工程建立、功能仿真、综合、实现及程序下载 |
| 硬件调试 | Testbench编写、时序分析、仿真波形分析及硬件调试 |

#### 2. 阶段项目：基于FPGA的多功能数字计时器设计（第一阶段简单例程自行查找练习，组会汇报）

**项目任务：**

1. 实现秒、分、时计数及数码管显示。
2. 实现按键控制、开始、暂停、复位及模式切换。
3. 使用有限状态机完成系统控制。
4. 完成Verilog代码编写、功能仿真及FPGA上板验证。

**阶段成果：** 完成一个可独立运行的FPGA数字计时系统，掌握基本的硬件设计和调试方法。

---

### 第二阶段：FPGA并行计算与图像处理（重点）

**培养目标：** 理解软件算法与硬件电路的区别，掌握图像处理算法的FPGA实现方法，建立并行计算和流水线设计思维。

#### 1. 学习内容

| 培养模块 | 具体学习内容 |
|---|---|
| 图像处理基础 | 图像灰度化、高斯滤波、Sobel边缘检测 |
| 硬件数值计算 | 定点数运算、数据位宽、溢出处理、计算精度分析 |
| 并行计算基础 | 并行计算结构、流水线设计及计算资源复用 |
| 图像数据处理 | 像素数据流、移位寄存器、行缓存、滑动窗口 |
| 算法硬件实现 | Python/C++算法向Verilog硬件模块的转换 |
| 软硬件验证 | Testbench测试、软件与硬件计算结果对比 |

#### 2. 阶段项目：基于FPGA的图像滤波与边缘检测系统（灵活掌握FPGA的并行加速）

**项目任务：**

1. 使用Python实现图像灰度化、高斯滤波和Sobel边缘检测。
2. 使用Verilog设计对应的图像处理模块。
3. 设计图像行缓存及3×3滑动窗口。
4. 利用流水线结构实现连续像素处理。
5. 对比Python与FPGA的计算结果，完成精度及性能测试。

**阶段成果：** 完成包含多个图像处理算法的FPGA计算系统，掌握图像数据流处理、硬件并行计算及软硬件一致性验证方法。

---

### 第三阶段：FPGA系统设计与软硬件协同开发（进阶）

**培养目标：** 掌握FPGA数据传输、高速存储硬件和系统集成技术，能够设计包含处理器与FPGA计算模块的完整图像处理系统。

#### 1. 学习内容

| 培养模块 | 具体学习内容 |
|---|---|
| 存储与缓存 | FIFO、BRAM、DDR及数据缓存管理 |
| 数据传输 | UART、AXI4、AXI DMA |
| Zynq系统开发 | ARM处理系统与FPGA可编程逻辑协同工作 |
| 硬件接口 | 摄像头、图像传输、显示及上位机通信 |
| 系统集成 | 多模块连接、数据流控制、图像输入与输出 |
| 系统性能分析 | 时钟频率、数据带宽、处理延迟及资源占用 |

#### 2. 阶段项目：基于Zynq的实时图像处理系统（学期任务）

**项目任务：**

1. 完成摄像头图像采集或其他图像数据输入。
2. 使用FPGA实现图像滤波和边缘检测。
3. 通过AXI及DMA实现处理器与FPGA之间的数据传输。
4. 设计上位机控制与图像显示程序。
5. 实现不同图像处理算法的动态切换。
6. 完成系统实时性、数据传输效率及硬件资源测试。

**阶段成果：** 完成具有图像输入、硬件处理、数据传输和结果显示功能的软硬件协同系统，具备独立进行FPGA系统开发的能力。

---

### 第四阶段：FPGA算法加速与计算架构设计（FPGA并行AI加速）

**培养目标：** 掌握计算密集型算法的FPGA硬件加速方法，能够根据算法特点设计高效的并行计算架构，并对计算性能及硬件资源进行优化。

#### 1. 学习内容

| 培养模块 | 具体学习内容 |
|---|---|
| 计算加速基础 | 矩阵运算、卷积计算、向量运算及算法复杂度分析 |
| 硬件加速方法 | RTL设计、HLS开发、算法模块硬件化 |
| 并行架构设计 | 并行计算单元、流水线优化、数据复用 |
| 存储架构设计 | 数据缓存、片上存储、存储带宽优化 |
| 硬件资源优化 | LUT、DSP、BRAM资源分配与优化 |
| 性能评估 | 定点量化、计算精度、吞吐率及延迟分析 |

#### 2. 阶段项目：基于FPGA的卷积计算加速器设计（难度较大）

**项目任务：**

1. 使用Python/C++实现二维卷积计算，建立软件参考模型。
2. 使用Verilog或HLS设计FPGA卷积计算模块。
3. 设计卷积窗口缓存及乘加运算单元。
4. 利用流水线与并行计算结构提高卷积处理效率。
5. 完成定点计算及数据位宽优化。
6. 对比软件与硬件计算结果，分析计算精度、吞吐率及资源占用。

**阶段成果：** 完成具有并行计算能力的FPGA卷积加速器，掌握计算密集型算法硬件化、并行计算架构设计及性能优化方法。

---

## 四、研究生培养考核与毕业要求

研究生培养采用阶段项目考核与最终科研成果考核相结合的方式。

各阶段均需完成理论学习、项目实现、实验验证及技术总结，前一阶段的项目成果作为后一阶段的技术基础。

| 培养阶段 | 阶段考核成果 | 核心能力 |
|---|---|---|
| 第一阶段 | FPGA多功能数字计时器 | 数字逻辑与Verilog设计 |
| 第二阶段 | FPGA图像滤波与边缘检测系统 | 图像处理与并行计算 |
| 第三阶段 | Zynq实时图像处理系统 | FPGA系统设计与软硬件协同 |
| 第四阶段 | FPGA卷积计算加速器 | 算法硬件加速与计算架构设计 |
