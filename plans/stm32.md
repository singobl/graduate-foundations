# 嵌入式 STM32 方向培养方案

[返回总导航](../README.md)

## 一、培养目标

面向电子信息类专业研究生，以嵌入式C、STM32硬件设计、外设驱动和FreeRTOS为基础，培养独立完成**电路设计、PCB制作、底层驱动、实时任务设计、系统联调与可靠性验证**的能力。以自研STM32F407四层开发板为统一平台，最终完成多源数据采集、存储与多总线通信终端，并在此基础上衔接具体科研课题。

**培养路线：** 嵌入式C与硬件基础 → STM32最小系统与PCB设计 → 外设与传感器驱动 → 通信、DMA与数据管理 → FreeRTOS与系统集成 → 综合项目与科研拓展。

## 二、分阶段培养内容

### 第一阶段：嵌入式C与硬件设计基础

**培养目标：** 能阅读数据手册，使用C语言编写模块化程序，掌握原理图及PCB设计基础。

| 学习模块 | 学习内容 |
| --- | --- |
| 嵌入式C | 指针、结构体、位运算、`volatile`、回调、内存与模块化编程 |
| MCU基础 | Cortex-M、寄存器、存储器映射、时钟树、启动与中断 |
| 电路基础 | 供电、时钟、复位、数字与模拟接口、电平匹配 |
| PCB设计 | 原理图、封装、器件选型、引脚规划、四层板布线与设计检查 |
| 开发调试 | STM32CubeMX、编译下载、ST-Link、示波器及逻辑分析仪 |

**阶段项目：STM32F407最小系统设计与验证**（打板完成测试）

1. 编写按键、LED和串口基础程序，完成下载与调试。
2. 绘制STM32F407最小系统原理图，确定电源、时钟、复位、SWD及引脚分配。
3. 完成四层PCB初版设计和设计检查，提交原理图、PCB及引脚分配表。

**阶段成果：** 可运行的基础固件、最小系统设计文件与设计检查记录。

### 第二阶段：自研开发板制作与基础外设

**培养目标：** 独立完成开发板制造、装配及上电调试，掌握常用片上外设。

| 学习模块 | 学习内容 |
| --- | --- |
| 硬件实现 | BOM、Gerber、钻孔与贴片文件、装配及上电检查 |
| 基础外设 | GPIO、EXTI、定时器、PWM、输入捕获、编码器、RTC与看门狗 |
| 模拟接口 | ADC、DAC、参考电压、采样与量化误差 |
| 调试方法 | 电源、时钟、复位、SWD验收；串口日志与关键波形测量 |

**阶段项目：STM32F407四层综合开发板制作与基础验收**

1. 完成开发板制造、装配及电源、时钟、SWD调试。
2. 验证LED、按键、串口、ADC、DAC、PWM和输入捕获等基础功能。
3. 完成DAC—ADC回环测试，记录关键电压、波形及问题清单。

**阶段成果：** 一块可稳定下载与运行程序的自研开发板，以及硬件设计文件和基础验收记录。

> **阶段门槛：** 电源、时钟和SWD通过验收后，再开展后续外设集成与综合系统测试。

### 第三阶段：通信接口与传感器驱动

**培养目标：** 能根据器件数据手册完成外设驱动、数据解析与可靠通信。

| 学习模块 | 学习内容 |
| --- | --- |
| 基础通信 | UART、I²C、SPI及通信时序 |
| 扩展通信 | RS485/Modbus RTU、CAN、USB CDC、以太网 |
| 传感器驱动 | 器件初始化、寄存器配置、数据换算与异常检测 |
| 协议与缓冲 | 帧格式、CRC、超时重发、环形缓冲区、粘包拆包 |
| 上位机 | Python串口收发、参数配置、数据记录及实时绘图 |

**阶段项目：多接口传感器采集与通信终端（重点）**

1. 接入I²C或SPI传感器，完成连续采样、解析及上位机显示。
2. 实现UART调试命令和至少一种扩展通信接口，完成收发与异常测试。
3. 将通信底层、器件驱动及应用逻辑分模块编写，提交接口测试记录。

**阶段成果：** 可运行的传感器采集与通信程序、上位机工具及接口测试报告。

### 第四阶段：DMA、数据存储与FreeRTOS

**培养目标：** 建立高效数据通路，掌握实时多任务调度与系统可靠性设计。

| 学习模块 | 学习内容 |
| --- | --- |
| 高速采集 | 定时器触发ADC、DMA、双缓冲及采样率与带宽分析 |
| 数据存储 | EEPROM、SPI Flash、microSD/FatFS、时间戳及CRC |
| FreeRTOS | 任务与优先级、队列、信号量、互斥锁、事件组、软件定时器 |
| 并发与可靠性 | 中断与任务协作、栈监测、看门狗、故障记录与恢复 |

**阶段项目：基于FreeRTOS的多任务采集与存储系统**

1. 采用定时器和DMA实现多通道ADC周期采样。
2. 分别建立采集、存储、通信及系统监控任务，实现任务间数据传递。
3. 将采样数据按时间戳写入microSD，支持参数掉电保存与异常恢复。
4. 测试采样连续性、存储正确性、任务运行与故障处理。

**阶段成果：** 具备连续采集、数据保存与任务管理能力的实时嵌入式系统。

## 三、最终综合项目：基于FreeRTOS的多源数据采集、存储与多总线通信终端

### 1. 项目目标

以**学生独立设计的STM32F407四层开发板**为硬件平台，集成多路模拟采集、信号输出、传感器、存储、多总线通信及实时任务管理，形成可连续稳定运行的完整嵌入式终端。

**系统数据流程：** 传感器/ADC输入 → 中断与DMA采集 → FreeRTOS任务调度 → 数据存储及多总线上传 → 上位机监测与参数配置；系统监控任务负责异常记录与恢复。

### 2. 综合项目任务

| 模块 | 核心任务 |
| --- | --- |
| 自研硬件 | 完成STM32F407四层板、供电、时钟、SWD和板载接口的设计及验收 |
| 采集与输出 | 4路ADC定时器触发与DMA采集；双路DAC输出与ADC回环；PWM、输入捕获及编码器测试 |
| 传感器与存储 | I²C传感器采集；EEPROM保存参数；SPI Flash擦写与CRC；microSD/FatFS记录带时间戳的数据 |
| 多总线通信 | UART命令行、RS485/Modbus RTU、CAN状态帧、USB CDC、以太网UDP/TCP通信 |
| 实时任务 | 分离采样、存储、通信、网络、控制及监控任务；使用队列、信号量、互斥锁等同步机制 |
| 上位机与可靠性 | 参数配置、数据显示、日志、看门狗、故障恢复及持续运行测试 |

### 3. 综合项目验收

| 验收项 | 最低要求 |
| --- | --- |
| 硬件 | 自研四层开发板完成装配；电源、时钟、SWD和基础接口通过验收 |
| ADC与DAC | 4路ADC各不低于10 kS/s；DAC输出1 kHz正弦波，完成DAC—ADC回环误差分析 |
| 串口与总线 | UART以115200 bit/s稳定收发；RS485以1 Mbit/s点对点通信并支持Modbus RTU；CAN以500 kbit/s或1 Mbit/s稳定收发 |
| 传感器与存储 | I²C连续采集正常；EEPROM掉电保存有效；SPI Flash读写CRC一致；microSD连续写入不低于100 kB/s |
| USB与网络 | USB CDC正常枚举与通信；以太网可Ping，UDP/TCP连续通信30 min无中断 |
| 实时与控制 | 完成PWM、输入捕获、编码器及故障输入验证；FreeRTOS任务同步和看门狗恢复正常 |
| 稳定性 | 全部功能协同运行24 h，无死机、异常复位及文件系统损坏 |

### 4. 最终交付

- 自研开发板原理图、PCB源文件、BOM、Gerber、装配说明与引脚分配表。
- STM32CubeMX配置文件、完整固件工程、上位机程序及版本管理仓库。
- 各接口测试记录、关键波形、综合性能与24 h连续运行报告。
- 系统问题清单、优化记录及面向后续科研课题的技术总结。

## 四、研究生培养考核与科研衔接

| 阶段 | 核心交付 | 考核重点 |
| --- | --- | --- |
| 第一阶段 | 最小系统设计与基础固件 | C语言、原理图、PCB及调试基础 |
| 第二阶段 | 自研四层开发板 | 硬件制作、上电验收与基础外设 |
| 第三阶段 | 传感器采集与通信终端 | 数据手册阅读、驱动开发与协议验证 |
| 第四阶段 | FreeRTOS采集与存储系统 | DMA、数据管理及实时任务协作 |
| 最终综合项目 | 多源采集、存储与多总线通信终端 | 独立系统集成、功能覆盖及稳定性 |

**科研衔接：** 在完成综合项目后，可根据实验室实际课题选择传感器采集、设备控制或自动化实验平台等方向，围绕**具体技术问题**开展改进设计与实验验证。综合项目的完成是工程能力考核；硕士毕业研究还应具备独立的研究问题、技术贡献和充分的实验证据，具体要求以学校和学院的学位标准为准。
