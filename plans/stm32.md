# 嵌入式 STM32 方向培养方案

[返回总导航](../README.md)

本方向以嵌入式 C、STM32 外设、实时系统和硬件调试为基础，以学生独立设计的 STM32F407 四层开发板和 FreeRTOS 综合项目作为实践闭环。先完成硬件基础验收，再开展各外设实验和系统联调。

## 阶段导航

| 阶段 | 工作重点 | 阶段交付 |
| --- | --- | --- |
| 知识与设计准备 | PCB 设计、C 语言、MCU、引脚与接口规划 | 基础实验、引脚分配和设计检查记录 |
| 首版开发板 | 原理图、四层 PCB、制造、装配与上电调试 | 可制造文件和电源、时钟、SWD 验收证据 |
| 外设与实时系统 | 驱动、中断、DMA、通信、存储和 FreeRTOS | 单模块实验与测试记录 |
| 综合项目 | 多源采集、存储、多总线通信与可靠性 | 完整固件、24 h 运行记录和技术报告 |
| 科研衔接 | 传感器采集、设备控制和实验平台 | 面向后续课题的独立系统 |

以下知识模块依据总方案整理；首版任务书的全部功能和量化指标保留在文末。总方案中的 CAN、USB 和以太网属于按课题扩展的能力，本仓库选用的首版综合项目已明确纳入这些接口，应按任务书验收。

## 培养目标

嵌入式方向面向传感器采集、设备控制、实验平台和嵌入式系统开发。学生应掌握面向嵌入式开发的C语言，理解微控制器的运行方式，能够独立完成外设配置、传感器驱动、通信协议、实时任务和系统调试。学习的重点不是记忆库函数，而是理解数据从硬件输入到软件处理再到通信输出的完整过程。

## 学习路线

PCB设计→嵌入式C → MCU基础 → 外设与中断 → 通信与传感器 → DMA与数据管理 → FreeRTOS → 控制与系统集成 → 可靠性测试

## 嵌入式C语言

C语言是STM32方向的基础。学生需要掌握变量、数据类型、条件与循环、函数、数组和字符串，并重点理解指针、结构体、枚举、联合体、typedef和函数指针。后续驱动开发大量使用地址、缓冲区和回调函数，指针和内存概念必须通过实际代码训练。

嵌入式C还包括位运算、宏定义、条件编译以及const、static、extern和volatile等关键字的使用。学生应理解栈、堆、全局区和静态区的区别，了解动态内存在嵌入式系统中的风险，能够使用头文件和源文件组织模块，并按照统一规范编写接口、注释和错误返回值。

- 数据类型及其位宽  指针与数组  结构体和枚举  字节序  位操作

- 宏和条件编译  变量作用域  volatile  回调函数  模块化编程

- 编译与链接的基本过程  内存布局  栈和堆  调试信息与警告处理

## 微控制器基础

学生需要理解ARM Cortex-M内核、存储器映射、Flash、RAM、寄存器、总线、时钟树、NVIC和启动过程。学习HAL库时，应知道库函数最终配置了哪些外设和寄存器；不要求一开始全部采用寄存器开发，但要能够借助参考手册定位配置问题。

调试能力与编程同等重要。学生应会使用ST-Link或同类调试器完成下载、单步运行、断点、变量观察和调用栈检查，并能借助串口日志、示波器和逻辑分析仪判断问题来自软件、时序还是硬件连接。

## 基础外设和数据采集

基础外设训练包括GPIO、外部中断、定时器、PWM、输入捕获、输出比较、ADC、DAC、看门狗和RTC。学生不仅要会调用配置工具生成工程，还要理解引脚模式、上拉下拉、采样精度、定时频率、占空比和中断优先级等参数对系统行为的影响。

ADC和高速数据采集应结合DMA学习。学生需要掌握采样率、量化误差、参考电压、噪声、缓冲区和数据搬运方式，并理解轮询、中断和DMA三种处理方法的适用范围。

## 通信接口和传感器驱动

串口、I2C和SPI是本方向必须掌握的通信接口，CAN、USB和以太网可根据课题需要继续学习。学生应能根据数据手册确认供电、电平、引脚、时钟、地址和通信时序，完成硬件连接、底层通信、寄存器配置、数据解析和错误检查。

通信训练还应覆盖数据帧、校验、超时、重发、环形缓冲区和粘包拆包等内容。驱动程序应分为底层接口、器件驱动和应用逻辑，避免把采集、解析和业务控制全部写在一个文件中。

- UART  I2C  SPI  CAN及课题需要的其他接口

- 数据帧  CRC或校验和  超时机制  环形缓冲区  非阻塞收发

- 传感器寄存器表  标定参数  原始数据换算  异常状态识别

## 实时系统和控制

完成单任务程序后，学生应学习FreeRTOS或实验室选用的实时操作系统。核心内容包括任务和优先级、调度、队列、信号量、互斥锁、事件组、软件定时器、内存管理以及中断与任务之间的数据交互。学生需要理解资源竞争、优先级反转、死锁和任务阻塞，能够根据实时性要求划分任务。

控制类项目还需要掌握状态机、PID基础、滤波、定时执行和安全状态设计。重点是形成稳定的系统结构：采集、控制、通信和故障处理各有明确职责，系统在传感器异常、通信中断或任务超时后能够进入可预期状态。

## 系统集成和可靠性

综合阶段应训练多传感器同步、数据缓存、时间戳、日志、参数保存、掉电恢复、看门狗和异常复位。对更新需求较高的项目，可进一步学习Bootloader、固件升级和版本管理；对低功耗设备，可学习睡眠模式、唤醒源和功耗测量。

Python在本方向作为辅助工具使用，主要用于串口上位机、数据保存、实时绘图、自动测试和离线分析。学生应能用Python构造测试数据、发送控制命令、检查返回结果并绘制采集曲线，但不以Python替代嵌入式C的核心训练。

## 实践项目与完成标准

项目可围绕多传感器采集终端、运动控制平台、自动化实验装置、相机和光源同步控制或设备状态监测展开。选题可以不同，但必须包含真实硬件、稳定通信、数据记录和故障处理。

- 能够根据一份陌生传感器数据手册完成接线、驱动、数据换算和基本标定。

- 能够设计中断或DMA驱动的数据通路，并说明缓冲区大小、采样率和通信带宽之间的关系。

- 能够完成FreeRTOS任务划分和任务间通信，定位常见的时序、内存和并发问题。

- 能够提交可运行工程、硬件连接说明、通信协议、测试记录和完整README。

## 学习资料

- C Primer Plus 或同类 C 语言教材，重点学习指针、结构体、内存和模块化编程。
- STM32 数据手册、参考手册、勘误表和 STM32Cube 官方文档。
- FreeRTOS 官方文档；Python 官方文档与 pyserial 用于上位机和自动测试。

## 首版开发板设计与验收任务书

以下任务适用于 STM32F407 四层开发板。首版全部基础电源、时钟和调试接口通过后，方可进入综合项目验收。

### 1 任务目标

完成一块以STM32F407为核心的四层综合开发板。首版应覆盖ADC、DAC、常用通信接口、外部存储及定时器控制接口，并能稳定运行FreeRTOS。该板经验收后作为后续嵌入式项目的统一实验平台。

### 2 首版范围

首版以功能完整、可制造和可调试为原则，不追求功能堆叠。原理图、PCB、装配调试和综合测试均由学生独立完成。设计依据为STM32F407数据手册及所选外围器件数据手册。

### 3 PCB及最小系统指标

| 项目 | 首版指标 |

| 主控 | STM32F407，LQFP144，最高168 MHz |
| 板层与尺寸 | 4层；1.6 mm；1 oz；尺寸不超过120 mm × 90 mm；四角M3安装孔 |
| 叠层 | Top：器件/信号；L2：完整GND；L3：电源；Bottom：信号 |
| 加工能力 | 最小线宽/线距6/6 mil；常规过孔0.3/0.6 mm |
| 供电 | USB Type-C 5 V与5 V端子输入；防反灌；3.3 V输出能力不低于1.5 A；VDDA经滤波供电 |
| 时钟 | 8 MHz HSE；32.768 kHz LSE |
| 启动调试 | SWD 10针接口、NRST按键、BOOT0配置、VBAT接口；关键电源和时钟测试点 |

### 6 首版不纳入的功能

首版不配置外部SDRAM、LCD/LTDC、摄像头、CAN FD、USB高速ULPI、Wi-Fi/蓝牙/4G、12～24 V宽压输入、±10 V模拟量、隔离CAN/RS485、板载ST-Link及电机功率级。上述功能仅保留必要扩展条件。

### 7 首版完成后的综合项目

#### 7.1 项目名称

基于FreeRTOS的多源数据采集、存储与多总线通信终端。

#### 7.2 项目任务

在自研开发板上建立FreeRTOS工程，将板载外设和外部扩展设备组成一个可连续运行的数据采集终端。系统应完成以下功能：

- ADC采用定时器触发和DMA完成4路周期扫描采样，至少包含板载电位器输入。

- DAC采用DMA输出正弦波，并通过跳帽回接ADC，完成波形采集与误差分析。

- I²C传感器连续采集温湿度或气压数据；AT24C64保存系统配置参数。

- W25Q128完成擦除、写入、读取及CRC校验；microSD采用FatFS保存带时间戳的数据文件。

- SPI1连接OLED或外部传感器，显示或采集系统状态。

- USART3提供调试命令行；RS485运行Modbus RTU；CAN周期发送系统状态帧。

- USB以CDC设备枚举并完成参数配置；以太网完成Ping、UDP数据上传及TCP配置通信。

- 完成PWM输出与输入捕获回环测试、编码器计数、按键、LED和蜂鸣器控制。

- 设置看门狗、运行状态记录和故障恢复机制，支持长时间连续运行。

#### 7.3 FreeRTOS实现要求

| 内容 | 最低要求 |
| --- | --- |
| 任务划分 | 采样、存储、通信、网络、控制及系统监控任务相互独立 |
| 同步机制 | 实际使用队列、信号量、互斥锁、事件组和软件定时器 |
| 数据通道 | ADC/DAC/串口等高频数据采用DMA；串口接收采用环形缓冲区 |
| 可靠性 | 任务栈余量可检查；错误可记录；看门狗能够恢复异常 |

### 8 综合项目验收指标

| 验收项 | 最低验收指标 |
| --- | --- |
| ADC | 4路均可采集；每路采样率不低于10 kS/s；数据可显示并保存 |
| DAC | 输出1 kHz正弦波；完成DAC—ADC回环并给出幅值与偏置误差 |
| UART | 115200 bit/s连续收发无异常，可执行命令并输出日志 |
| RS485 | 1 Mbit/s点对点通信通过；Modbus RTU读写寄存器正常 |
| CAN | 500 kbit/s或1 Mbit/s稳定收发状态帧 |
| I²C | 传感器连续读取正常；EEPROM参数掉电保存与恢复正确 |
| SPI | 外部扩展设备工作正常；Flash擦写读取CRC一致 |
| microSD | FatFS挂载、建文件和连续写入正常；记录速率不低于100 kB/s |
| USB | CDC正确枚举，可收发命令与数据 |
| Ethernet | 可Ping；UDP与TCP通信连续运行30 min无中断 |
| 定时器接口 | PWM频率、占空比及死区可测；捕获、编码器和故障输入有效 |
| 系统运行 | 全部功能在FreeRTOS下协同运行24 h，无死机、异常复位及文件系统损坏 |

### 10 结论判定

首版开发板完成装配且全部基础电源、时钟、调试接口通过后，方可进入综合项目验收。第8节项目全部通过，且提交材料完整，判定首版任务完成。
